📖 2-Minute Setup Guide (Click to view)
  1. Open sheets.google.com and create a new blank sheet named Govind Garden Guest Care.
  2. Click top menu Extensions → Apps Script.
  3. Click "Copy Google Sheet Script" button above, delete any existing code in Apps Script, and paste it.
  4. Click Deploy → New deployment → Select type Web app.
  5. Set Execute as: Me, and Who has access: Anyone → Click Deploy & Authorize.
  6. Copy the Web app URL, paste it in the box above, and click Connect & Sync Now.
